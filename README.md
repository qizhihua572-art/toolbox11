# Q工坊工具箱

一个不会写代码的普通人，用 AI 每周做一个能用的小工具。全部纯前端、零服务器成本，GitHub Pages 直接托管。

## 工具列表

| # | 工具 | 目录 | 说明 |
|---|---|---|---|
| 1 | 修仙世界模拟器 |（独立仓库 `xianxia-world-simulator`）| 网文作者防吃书工具 |
| 2 | 口播稿生成器 | `koubogao/` | 3 秒生成口播稿，自带提词器 |
| 3 | X 帖子钩子生成器 | `x-hook-generator/` | 6 种钩子结构生成完整帖子，带发布自检 |

## 目录结构

```
toolbox/
├── index.html          # 工具箱导航首页
├── koubogao/           # 工具 #2：口播稿生成器
├── x-hook-generator/   # 工具 #3：X 帖子钩子生成器
└── ...                 # 后续工具每个一个文件夹
```

新工具直接加一个文件夹即可，无需新建仓库。
